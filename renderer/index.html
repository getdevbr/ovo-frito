📖 Manual Oficial — Carro do Ovo (100% Local-First API Client)

        
      

      

        

          
🥚 1. Visão Geral & Filosofia 100% Local-First

          

            O Carro do Ovo é um cliente de APIs moderno, portátil e 100% offline. Nenhum dado sai da sua máquina para nuvens de terceiros: todas as suas Collections, Environments, Profiles, Histórico, Cookies e Configurações ficam salvos localmente na pasta ./data/ e podem ser exportados no formato nativo .ovo.
          

        


        

          
⌨️ 2. Atalhos de Teclado Essenciais

          

            
Ctrl + Espaço
Abre o Autocomplete de Variáveis ({{...}}) em qualquer campo de texto (URL, Params, Headers, Auth, Body) com navegação por setas (↑/↓) e Enter.

            
Ctrl + Enter
Dispara a requisição ativa (Send).

            
Ctrl + S
Salva as alterações da aba atual na Collection vinculada (remove o indicador ● de pendência).

            
Ctrl + K
Abre a Command Palette (busca rápida de requisições, troca de Profile/Environment, layout e ações).

          

        


        

          
🎨 3. Environments, Profiles Livres, Contorno Colorido & Trava Anti-Acidente

          
    
            
  • Criação Livre de Profiles: Clique no botão ✎ ao lado do Environment na barra superior para criar quantos Profiles quiser (ex: Local, Staging, Cliente X, Produção), sem nomes engessados.
    • 
            
  • Contorno Visual na Requisição: Cada Profile pode ter uma cor personalizada que contorna todo o painel da requisição para você sempre saber em qual ambiente está disparando.
    • 
            
  • Trava Anti-Acidente (🛡️): Marque a opção no Profile para exigir confirmação antes de disparar métodos destrutivos (DELETE, PUT, PATCH, POST).
    • 
            
  • Comparador A/B (⚖️ Comparar Profile/Env): Dispara a mesma requisição em dois Profiles/Environments e exibe o Diff Visual lado a lado.
    • 
          

        


        

          
🔧 4. Variáveis, Geradores Dinâmicos BR 🇧🇷 & Request Chaining

          

            Pressione Ctrl + Espaço ou digite {{ em qualquer campo para listar e inserir variáveis. Ordem de precedência: Data File (Runner) > Profile Ativo > Environment > Collection.
          

          

            
{{$uuid}} / {{$guid}}
Gera um UUID v4 aleatório a cada disparo.

            
{{$timestamp}} / {{$isoDate}}
Timestamp Unix (segundos) ou data ISO-8601 UTC atual.

            
{{$randomCPF}}
Gera um CPF brasileiro válido (11 dígitos com dígito verificador real).

            
{{$randomCNPJ}}
Gera um CNPJ brasileiro válido (14 dígitos com dígito verificador real).

            
{{$randomCelular}} / {{$randomEmail}}
Gera celular brasileiro (DDD + 9xxxxxxxx) ou e-mail aleatório.

            
{{@NomeReq.json.campo}}
Request Chaining: Lê diretamente um valor da última resposta de outra requisição (ex: {{@Login.json.access_token}}).

          

        


        

          
🔐 5. Autenticação Herdada, Inspetor JWT Offline, Proxy & mTLS

          
    
            
  • Herdar da Collection (🔗): Configure o Auth padrão clicando em ⚙ na Collection e selecione "Herdar da Collection" nas requisições.
    • 
            
  • Inspetor JWT 100% Local: Ao usar um token JWT na aba Authorization (mesmo via {{variavel}}), o Header e o Payload são decodificados offline com alerta de expiração (exp).
    • 
            
  • Proxy HTTP/HTTPS, SSL & mTLS: Em ⚙ Configurações, configure Proxy com túnel CONNECT, desative verificação de certificado SSL autoassinado (rejectUnauthorized: false) ou anexe seu certificado digital cliente (.pfx / .p12 / .crt) para handshakes mTLS.
    • 
          

        

      

      

        Documentação também disponível no arquivo MANUAL.md na raiz do projeto.
